# Firmware

This directory contains the Arduino C++ code I've written while developing Buddy, from my earliest embedded systems experiments to the current working robot.

## Structure

### `BUDDY-current/`
The latest working firmware running on Buddy as of October 22nd, including motor control, sensor integration, and obstacle avoidance.

### `Iterations/`
A non-exhaustive collection of earlier sketches and code I wrote while learning the fundamentals of embedded systems and gradually building Buddy. These files document my progress, experiments, and the development of the robot over time.

These sketches are preserved to show how the project evolved. They aren't necessarily part of Buddy's current firmware.

## Running the Code

The firmware is written in Arduino C++ for the Arduino Uno R3.

Open `buddy/buddy.ino` in the Arduino IDE, select the Arduino Uno board and appropriate port, install the required sensor libraries, and upload the sketch.

Earlier iterations can be opened and tested separately.
